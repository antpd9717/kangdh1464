# 스팟 디렉토리 리서치 — 소지역별 실제 장소 목록

마지막 갱신: 2026-09-04 (planner)

## 작업 방식 및 원칙
- 사용자 요청에 따라 콘텐츠 형식을 "코스/플랜형"에서 "소지역 선택 → 실제 스팟 목록형"으로 전환하기 위한 리서치 자료다.
- 모든 스팟은 WebSearch(및 필요시 WebFetch)로 실제 검색 결과에 이름이 등장하는 것만 실었다. 주소·영업시간·가격 등 세부 정보는 검색 스니펫에 명시적으로 나온 경우에만 적었고, 그 외에는 "확인 필요"로 남겼다.
- 검색해도 구체적인 상호명이 나오지 않거나 신뢰도가 낮은 곳(단발성 언급, 실존 확인 어려움)은 목록에서 제외했다.
- 이 문서는 리서치 원자료이며, 실제 페이지 제작 시 작성 담당이 각 스팟의 주소/영업시간 등을 별도로 검증해야 한다.

## 우메다&middot;난바 (오사카 / 먹을 것) — 우선순위 1

- **신파치 식당 (우메다점)** — 생선구이 정식을 파는 조식 맛집. 숯불에 구워 즉석 제공, 생선정식 1인분 2,500~2,700엔대로 가성비 좋음. (검색 근거: run-twosonmom.com 블로그, jkoreap.com)
- **신파치 난바나카이도오리점** — 위 신파치 식당의 난바 지점. 생선구이 중심 일본 가정식. (검색 근거: pappa.nblogos.com)
- **메시아 24시 센니치마에** — 난바역 인근 24시간 영업 일본 가정식 식당. 메뉴 다양, 가격 합리적. (검색 근거: pappa.nblogos.com)
- **하나마루켄 24시** — 난바역 인근 24시간 영업 라멘 전문점. (검색 근거: pappa.nblogos.com)
- **마츠타케** — 난바역 인근 카페형 식당, 커피와 토스트로 아침식사 가능. (검색 근거: pappa.nblogos.com)
- **사키모토 베이커리** — 난바역 인근 베이커리 카페, 토스트·샌드위치 판매. (검색 근거: pappa.nblogos.com)
- **하코유메** — 난바역 인근 주먹밥(오니기리) 전문점. 오전 6시 30분부터 영업, 주문 즉시 만들어 제공. (검색 근거: matcha-jp.com)
- **더 그랜드 카페** — 우메다역 도보 5분, 힐튼플라자웨스트 6층. 통창 뷰의 브런치 카페. (검색 근거: kansai.momentum-tk.com — 정확히는 "브런치" 소개 글이라 이른 아침 영업 여부는 확인 필요)
- **소홀름 카페 다이닝 우메다(Soholm)** — 북유럽풍 카페, 통밀 팬케이크 전문. 이른 오픈 가능성 언급되나 정확한 오픈 시각은 확인 필요. (검색 근거: jkoreap.com)

비고: "조식/아침 일찍"으로 명확히 확인된 곳은 신파치 식당·메시아24시·하나마루켄24시·마츠타케·사키모토 베이커리·하코유메이며, 더 그랜드 카페·소홀름은 브런치 카페로 소개되어 실제 이른 아침 영업 여부는 별도 확인이 필요하다.

## 나오시마 (세토내해&middot;호쿠리쿠 / 할 것) — 우선순위 1

- **아트하우스 프로젝트(이에 프로젝트)** — 혼무라 지역의 옛 민가 7채를 예술가·건축가가 개조한 전시 공간. "킨자"를 제외한 6채는 통합권으로 관람 가능. (검색 근거: getabout.hanatour.com)
- **쿠사마 야요이의 호박(노란 호박&middot;빨간 호박)** — 나오시마를 상징하는 설치미술 포토존. 빨간 호박은 미야노우라 항 인근에 위치. (검색 근거: elle.co.kr, arte365.kr)
- **나오시마 목욕탕 'I♥湯' (아이러브유)** — 작가 신로 오타케가 작업한 대중목욕탕. 실제 주민도 이용하는 목욕탕이자 예술 작품. (검색 근거: elle.co.kr)
