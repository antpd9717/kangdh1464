# FAQ (자주 묻는 질문)

이 문서는 사이트 방문자 문의(댓글, 문의폼, 이메일 등) 중 반복적으로 들어오는 질문과
CS팀(support 에이전트)이 검토·승인한 답변을 정리해 재사용하기 위한 문서입니다.

> **현재 상태 안내 (2026-09-13 기준)**
> 오늘 개발팀이 `about/index.html`의 "콘텐츠 진행 상황" 섹션 문구를 정정했습니다. 기존에는
> 실제로 존재하지 않는 홈페이지 "콘텐츠 캘린더" 섹션을 안내하는 오류가 있었는데, 실제
> 홈페이지 구조인 `#articles` 섹션("지역별 스팟 미리보기" — 지역별로 스팟 2~3개 미리보기 +
> 지역 페이지로 링크)에 맞게 고쳤습니다. 방문자에게 잘못된 사이트 안내를 하던 문제가
> 해소된, 화면에 보이는 문구 자체가 바뀐 변경입니다.
>
> 개발팀은 또한 `assets/js/main.js`의 오래된 주석("주제/브랜드 확정 전 임시 골격" — 니치/
> 브랜드는 이미 여러 날 전 확정됨)을 실제 로직 설명으로 정리했습니다. 이는 코드 주석만의
> 변경으로, 방문자 화면에는 영향이 없습니다.
>
> 디자인팀은 스팟 카드 하단에 JS로 추가되는 "📍 지도에서 보기" 링크(`.spot-map-link`)가
> 모바일에서 패딩 없이 텍스트 줄높이만으로 탭 영역을 구성해 계산상 약 23.8px로 WCAG 최소
> 권장 탭 크기(24px)에도 못 미쳤던 것을 확인하고, 상하 패딩을 추가해 약 39.8px로 넓혔습니다.
> 방문자가 모바일에서 지도 링크를 누르기 조금 더 편해지는 시각적 변경입니다.
>
> 디자인팀은 또한 긴 스팟명(예: "CIRCULABLE SUPPLY 시모키타자와점")이 모바일에서
> 줄바꿈/넘침 문제가 있는지 컨테이너 폭 대비 글자 폭을 계산으로 검토했으나, 문제가 없음을
> 확인해 코드 변경은 하지 않았습니다.
>
> 그 외 새 지역/글 콘텐츠 추가나 사이트 니치 변경은 오늘 없었습니다. 발행된 글은 여전히
> 3편(오사카 조식, 나오시마 당일치기, 우레시노 온천) 그대로입니다.
>
> `sitemap.xml`/`robots.txt`, 그리고 각 글의 `og:url`/`canonical`/`og:image`/`twitter:image`
> (실제 배포 도메인 미확정으로 대기 상태) 플레이스홀더는 오늘도 변경되지 않았습니다. 각 글
> 하단의 "예약 & 이동 정보"(제휴 링크) 섹션도 여전히 자리만 마련된 상태로 미연동입니다.
>
> 사이트 니치(주제)는 계속 확정 상태입니다: 일본 지역별 "가볼만한 곳 + 맛집" 정보를 다루며,
> 특히 오사카·나오시마·우레시노 등 경쟁이 낮은 롱테일 지역/테마부터 공략하는 구조입니다.
>
> 실제 문의가 들어오면 이 문서 하단에 "실제 문의" 섹션을 추가해 누적 관리합니다.

## 문서 구조 (사용 방법)

각 FAQ 항목은 아래 포맷을 따릅니다.

```
### Q. [질문 요약]

- **분류**: (예: 정책 안내 / 콘텐츠 오류 제보 / 광고·제휴 / 이용 방법 / 기타)
- **최초 등록일**: YYYY-MM-DD
- **출처**: 예시 여부 또는 실제 문의(등록일·채널만 기록, 개인정보 기록 금지)
- **답변**:
  실제 답변 내용을 여기에 작성합니다. 사이트 콘텐츠(발행된 글)를 근거로 하며,
  근거가 없는 내용은 "확인 후 안내드리겠습니다"로 표시합니다.
- **관련 콘텐츠 링크**: (해당 답변의 근거가 된 게시글/페이지 URL 또는 "없음")
- **비고**: (추가 참고사항, 검토 필요 여부 등)
```

신규 문의를 FAQ로 편입할 때는:
1. 동일/유사 질문이 이미 있는지 먼저 확인한다.
2. 답변 초안은 사이트에 실제 발행된 콘텐츠를 근거로 작성하고, 근거가 없으면 "확인 필요"로 명시한다.
3. 문의자의 이메일, 전화번호 등 개인정보는 이 문서에 기록하지 않는다.
4. 답변은 초안 상태로만 두고, 사용자가 직접 발송하거나 승인("보내줘")한 뒤에만 발송 완료로 표시한다.
