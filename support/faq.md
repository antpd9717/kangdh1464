# FAQ (자주 묻는 질문)

이 문서는 사이트 방문자 문의(댓글, 문의폼, 이메일 등) 중 반복적으로 들어오는 질문과
CS팀(support 에이전트)이 검토·승인한 답변을 정리해 재사용하기 위한 문서입니다.

> **현재 상태 안내 (2026-09-03 기준)**
> 이 사이트는 아직 실제로 발행/공개되지 않았고, 저장소 내 어디에도 실제 방문자 문의(문의폼 제출,
> 댓글, 이메일 등) 데이터가 존재하지 않습니다. 아래 항목 중 "실제 문의"로 표시되지 않은 것은
> 전부 **예시(실제 문의 아님)**이며, 사이트 니치(주제)가 정해지지 않은 상태에서도 통용되는
> 일반적/정책 수준의 안내만 포함되어 있습니다. 특정 상품·서비스 내용은 지어내지 않았습니다.
> 실제 문의가 들어오면 이 문서 하단에 "실제 문의" 섹션을 추가해 누적 관리합니다.

---

## 문서 구조 (사용 방법)

각 FAQ 항목은 아래 포맷을 따릅니다.

```
### Q. [질문 요약]

- **분류**: (예: 정책 안내 / 콘텐츠 오류 제보 / 광고·제휴 / 이용 방법 / 기타)
- **최초 등록일**: YYYY-MM-DD
- **출처**: 예시 여부 또는 실제 문의(등록일·채널만 기록, 개인정보 기록 금지)
- **답변**:
  실제 답변 내용을 여기에 작성합니다. 사이트 콘텐츠(발행된 글)를 근거로 하며,
  근거가 없는 내용은 "확인 후 안내드리겠습니다"로 표시합니다.
- **관련 콘텐츠 링크**: (해당 답변의 근거가 된 게시글/페이지 URL 또는 "없음")
- **비고**: (추가 참고사항, 검토 필요 여부 등)
```

신규 문의를 FAQ로 편입할 때는:
1. 동일/유사 질문이 이미 있는지 먼저 확인한다.
2. 답변 초안은 사이트에 실제 발행된 콘텐츠를 근거로 작성하고, 근거가 없으면 "확인 필요"로 명시한다.
3. 문의자의 이메일, 전화번호 등 개인정보는 이 문서에 기록하지 않는다.
4. 답변은 초안 상태로만 두고, 사용자가 직접 발송하거나 승인("보내줘")한 뒤에만 발송 완료로 표시한다.

## 예시 항목 (실제 문의 아님 — 정책 수준 일반 안내)

아래 항목은 사이트 니치가 정해지지 않은 현재 시점에서도 유효한 구조적 안내이며,
실제 방문자 문의에 대한 답변이 아닙니다. 니치가 확정되고 실제 문의가 들어오면
그에 맞게 수정하거나 실제 문의 섹션으로 대체합니다.

### Q. 광고/제휴 문의는 어떻게 하나요? (예시, 실제 문의 아님)

- **분류**: 정책 안내
- **최초 등록일**: 2026-09-03
- **출처**: 예시 (실제 문의 아님)
- **답변**:
  안녕하세요, 문의 주셔서 감사합니다. 광고·제휴 관련 문의는 [문의 채널 확정 후 기입]으로
  보내주시면 담당자가 검토 후 순차적으로 회신드리고 있습니다. 다만 현재 사이트는 콘텐츠
  준비 단계로, 광고/제휴 진행 여부 및 조건은 아직 정해지지 않았습니다. 확정되는 대로
  안내드리겠습니다.
- **관련 콘텐츠 링크**: 없음
- **비고**: 사이트 발행 및 문의 채널(이메일/폼) 확정 후 실제 연락처로 업데이트 필요.

### Q. 콘텐츠(글) 오류를 발견하면 어떻게 제보하나요? (예시, 실제 문의 아님)

- **분류**: 콘텐츠 오류 제보
- **최초 등록일**: 2026-09-03
- **출처**: 예시 (실제 문의 아님)
- **답변**:
  알려주셔서 감사합니다. 오류를 발견하신 게시글의 제목(또는 URL)과 구체적으로 어떤
  부분이 잘못되었는지 함께 알려주시면 확인 후 빠르게 수정하겠습니다. 확인에는 다소
  시간이 걸릴 수 있는 점 양해 부탁드립니다.
- **관련 콘텐츠 링크**: 없음 (제보 대상 글에 따라 다름)
- **비고**: 실제 제보가 들어오면 해당 글 URL과 함께 "실제 문의" 섹션에 개별 기록.

### Q. 이 사이트는 무엇을 다루는 곳인가요? (예시, 실제 문의 아님)

- **분류**: 이용 방법 / 정책 안내
- **최초 등록일**: 2026-09-03
- **출처**: 예시 (실제 문의 아님)
- **답변**:
  현재 사이트는 콘텐츠 준비 중으로, 아직 정식으로 공개되지 않았습니다. 정식 오픈 후
  다루는 주제와 이용 방법을 이 자리에서 안내드리겠습니다.
- **관련 콘텐츠 링크**: 없음
- **비고**: 사이트 니치가 확정되고 첫 콘텐츠가 발행되면 이 답변을 실제 내용으로 교체.
