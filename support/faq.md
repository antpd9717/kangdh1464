# FAQ (자주 묻는 질문)

이 문서는 사이트 방문자 문의(댓글, 문의폼, 이메일 등) 중 반복적으로 들어오는 질문과
CS팀(support 에이전트)이 검토·승인한 답변을 정리해 재사용하기 위한 문서입니다.

> **현재 상태 안내 (2026-09-05 기준)**
> 저장소 전체(코드, 콘텐츠, 문서, git 이력)를 다시 점검했으나 문의폼 제출, 댓글, 이메일 등
> 실제 방문자 문의 데이터는 여전히 어디에도 존재하지 않습니다. 아래 항목 중 "실제 문의"로
> 표시되지 않은 것은 전부 **예시(실제 문의 아님)**입니다.
>
> 사이트 니치(주제)는 계속 확정 상태입니다: 일본 지역별 "가볼만한 곳 + 맛집" 정보를 다루며,
> 특히 오사카·나오시마·우레시노 등 경쟁이 낮은 롱테일 지역/테마부터 공략하는 구조입니다.
> 지역 허브 페이지 6개(오사카/도쿄/후쿠오카/삿포로/오키나와/세토내해·호쿠리쿠)와 글 3편
> (오사카 조식, 나오시마 당일치기, 우레시노 온천)이 만들어져 있지만, **글 본문은 여전히
> "콘텐츠 작성 예정" placeholder 상태**로 실제 정보(맛집명, 코스, 팁 등)는 채워지지
> 않았습니다 (`content/osaka-breakfast`, `content/naoshima-day-trip`,
> `content/ureshino-onsen` 3개 파일을 오늘 직접 다시 열어 확인함 — 어제와 동일).
>
> 오늘(2026-09-05) 새로 확인된 변화: 지역 허브 페이지(예: `region/osaka/index.html`)에
> "음식 종류 필터"(가정식·정식, 라멘, 카페·브런치, 베이커리·분식 등)가 추가되어 있습니다.
> 이는 아직 글 본문이 채워지지 않은 것과 별개로, 허브 페이지의 스팟 카드 자체는 실제
> 정보(스팟명·소지역·카테고리)를 담고 있으며 필터로 좁혀볼 수 있다는 뜻입니다. 아래 예시
> 답변에 관련된 부분만 짧게 반영했습니다.
>
> 실제 문의가 들어오면 이 문서 하단에 "실제 문의" 섹션을 추가해 누적 관리합니다.

## 문서 구조 (사용 방법)

각 FAQ 항목은 아래 포맷을 따릅니다.

```
### Q. [질문 요약]

- **분류**: (예: 정책 안내 / 콘텐츠 오류 제보 / 광고·제휴 / 이용 방법 / 기타)
- **최초 등록일**: YYYY-MM-DD
- **출처**: 예시 여부 또는 실제 문의(등록일·채널만 기록, 개인정보 기록 금지)
- **답변**:
  실제 답변 내용을 여기에 작성합니다. 사이트 콘텐츠(발행된 글)를 근거로 하며,
  근거가 없는 내용은 "확인 후 안내드리겠습니다"로 표시합니다.
- **관련 콘텐츠 링크**: (해당 답변의 근거가 된 게시글/페이지 URL 또는 "없음")
- **비고**: (추가 참고사항, 검토 필요 여부 등)
```

신규 문의를 FAQ로 편입할 때는:
1. 동일/유사 질문이 이미 있는지 먼저 확인한다.
2. 답변 초안은 사이트에 실제 발행된 콘텐츠를 근거로 작성하고, 근거가 없으면 "확인 필요"로 명시한다.
3. 문의자의 이메일, 전화번호 등 개인정보는 이 문서에 기록하지 않는다.
4. 답변은 초안 상태로만 두고, 사용자가 직접 발송하거나 승인("보내줘")한 뒤에만 발송 완료로 표시한다.
