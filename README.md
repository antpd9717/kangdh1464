# kangdh1464

부업 사이트 프로젝트. 현재는 사이트 주제/니치가 아직 확정되지 않은 상태로,
어떤 주제가 정해지더라도 재사용 가능한 최소한의 정적 사이트 기술 골격만 구성되어 있습니다.

## 구조

```
.
├── index.html            # 임시 placeholder 페이지 ("콘텐츠 준비 중")
├── assets/
│   ├── css/style.css     # 최소 기본 스타일
│   └── js/main.js        # 최소 기본 스크립트
├── content/              # 향후 글이 들어갈 폴더 (현재 비어 있음)
├── netlify.toml          # 정적 사이트 배포용 최소 설정 (git 연동 자동 배포 전제)
└── .claude/agents/       # 운영 에이전트(팀) 설정
```

## 디자인 톤

`assets/css/style.css`는 **니치 확정 전 임시 기본 톤**입니다. 특정 업종/브랜드 색감을
가정하지 않은 무난한 라이트/다크 겸용 팔레트이며, 파일 상단의 CSS 변수(`:root`)만
교체하면 실제 브랜드 톤으로 손쉽게 전환할 수 있도록 설계했습니다.

## 배포

이 저장소는 Git 저장소 연동 기반 자동 배포(예: Netlify/Vercel)를 전제로 합니다.
빌드 과정 없이 정적 파일을 그대로 배포(publish)하도록 구성되어 있습니다.
**CLI로 직접 배포하지 않고, `git push origin main`을 통해서만 배포합니다.**

## 다음 단계

- **기획팀(`planner`)이 사이트의 주제/니치를 정하고 `planning/content-plan.md`에
  콘텐츠 계획을 확정해야 합니다.** 그 전까지는 실제 콘텐츠나 브랜딩을 추가하지 않습니다.
- 콘텐츠 계획이 나오면 `content/` 폴더에 글을 추가하고, `index.html`의 placeholder를
  실제 콘텐츠로 교체합니다.
