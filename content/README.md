# content

이 폴더는 발행되는 글(콘텐츠)이 들어가는 자리입니다.

- 니치와 콘텐츠 계획은 `planning/content-plan.md`(기획팀)에 정리되어 있습니다.
- 각 글은 `content/<slug>/index.html` 구조를 따릅니다 (예: `content/osaka-breakfast/index.html`).
- 현재는 우선순위 상위 3개 글의 **구조 뼈대**만 만들어져 있습니다 (`osaka-breakfast`, `naoshima-day-trip`, `ureshino-onsen`). 헤딩/섹션 틀만 있고, 본문은 작성팀이 채울 때까지 "콘텐츠 작성 예정" placeholder로 남겨두었습니다.
- 새 글을 추가할 때는 기존 글의 헤더/네비게이션/브레드크럼/`함께 보면 좋은 글` 구조를 그대로 재사용하세요.
