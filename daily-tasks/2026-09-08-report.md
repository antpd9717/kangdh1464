## 2. 팀별 작업 및 검수 결과

### 개발팀 (developer)
**지시 내용**: Playwright + Chromium으로 발행된 13개 페이지 전부를 실제 브라우저로 방문해
콘솔 에러/네트워크 실패를 수집하고, 지역 허브 필터·뒤로가기 버튼·구글맵 링크를 실제로
클릭해 런타임 동작을 검증. 문제 발견 시 최소 수정.

**산출물**:
- **실제 결함 발견 및 수정**: 13개 페이지 전부에서 `favicon.ico` 404가 발생하고 콘솔에
  에러가 찍히는 것을 실측(`page.on('console')`/`page.on('request')`)으로 확인. 원인은
  모든 HTML에 `<link rel="icon">`가 없었던 것. 13개 파일 head에 각각
  `<link rel="icon" href="data:,">` 한 줄씩 추가(브랜드 파비콘 이미지는 아직 미확정이라
  새 이미지 자산은 만들지 않음). 수정 후 재검증에서 404가 완전히 사라짐을 확인.
- Google Fonts `@import` 연결 실패는 이 샌드박스 환경이 Chromium의 아웃바운드 인터넷을
  막고 있어 생긴 **테스트 환경 제약**이지 사이트 결함이 아님을 근거(curl은 200, CSS에
  정상 폴백 폰트 스택 존재)와 함께 판단해 수정하지 않음 — 타당한 판단.
- 필터 pill(오사카/후쿠오카/오키나와 전체 조합) 클릭 테스트: 노출되는 카드 수가 기대값과
  전부 일치, 콘솔 에러 없음.
- 뒤로가기 버튼: "홈→지역 이동 후 뒤로가기", "새 탭에서 바로 열림" 두 실사용 시나리오 모두
  정상 동작 확인.
- 구글맵 링크: href 포맷/속성(`target="_blank"`, `rel="noopener"`) 실제 DOM에서 확인,
  카드 수와 링크 수 정확히 일치. 실제 구글맵 페이지 로딩까지는 샌드박스 인터넷 제약으로
  검증 불가(정직하게 한계로 고지).

**검수**:
- ✅ **마스터가 직접 재확인**: `git diff --stat`으로 13개 파일 각 +1줄(합계 13줄)임을
  확인, 두 파일(`index.html`, `region/osaka/index.html`) 전체 diff를 직접 읽어 보고
  내용과 정확히 일치함을 확인.
- ✅ 범위 준수 — 다른 파일/기능 변경 없음, git add/commit/push는 하지 않고 마스터에게 위임.
- ✅ 자체 검증 근거 충분 — 실제 콘솔/네트워크 로그, 클릭 테스트 결과를 구체적으로 제시.
  검증 못 한 부분(외부 인터넷 필요한 항목)을 명확히 구분해 고지.
- 위 결과를 검증 후 `git commit`(`9b48290`) + `git push origin main`으로 반영했다.
