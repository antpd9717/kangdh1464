  대조); JSON-LD headline 접미사가 3편 모두 제거되고 다른 필드는 무변경; ureshino-onsen 히어로
  alt가 사이트 내 검증된 값으로 통일됨; `assets/css/style.css`의 지역 카드 aspect-ratio
  오버라이드가 셀렉터 1곳(5→4)만 교체되고 다른 규칙은 무변경, 중괄호 174/174 유지;
  `support/faq.md`에 신규 FAQ 1건이 순수 추가되고(마스터가 CS팀의 범위 위반 1건을 발견해
  직접 원복) 기존 항목·"실제 문의" 섹션은 무변경; 신규 FAQ 답변 내용(4개 지역의 빈 카테고리
  상태)이 각 HTML 파일의 `data-category` 실제 값과 정확히 일치; 사이트 내부 링크/자산 참조
  전수 검사 결과 깨진 링크·참조 0건(14개 HTML 전 페이지 스캔); `main.js` 문법 검사 통과;
  로컬 main 브랜치가 origin/main과 fast-forward로 정상 동기화됨.
- **검증되지 않음(정직하게 미확인으로 남김)**: footer-nav·지역 카드 사진 비율 수정이 실제
  브라우저에서 의도대로 보이는지(Playwright 등 렌더링 검증 미수행); 실제 방문자 문의 채널
  확인; 실제 배포 도메인·인터넷 공개 여부; 실제 AdSense 광고 게재 여부; 빈 카테고리(먹을 것/
  할 것) 콘텐츠에 대한 실제 방문자 수요.
