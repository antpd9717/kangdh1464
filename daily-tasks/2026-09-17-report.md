### 디자인팀 (designer)
**지시 내용**: 개발팀이 추가한 `.skip-link`에 대해 평소에는 화면 밖으로 숨기고
(스크린리더는 계속 읽을 수 있도록 `display:none` 금지), 키보드 포커스 시에만
상단에 눈에 띄게 나타나는 표준 접근성 스타일 추가. 기존 디자인 토큰 재사용,
라이트/다크 모드 모두 확인. 기능(HTML/JS)은 건드리지 않음.

**산출물**:
- `assets/css/style.css`에 `.skip-link`/`.skip-link:focus` 규칙만 추가(+25줄).
  기존 `--color-accent`/`--color-accent-contrast`(이미 `.map-pin-circle` 등에서
  라이트·다크 양쪽 대비 검증된 조합), `--space-2`, `--radius-md`, `--shadow-md`,
  `--font-size-sm` 토큰만 재사용. `display:none` 대신 `top:-100px` 화면 밖 이동
  방식 사용, `z-index:1000`으로 헤더 위에 오도록 처리.
- Playwright로 `index.html`/`region/osaka/index.html`/`404.html` × 라이트/다크
  6개 조합에서 평소 비노출·포커스 시 노출을 스크린샷 기반으로 확인. 애니메이션
  전환(`transition: top 0.15s`) 때문에 포커스 직후 0ms 스크린샷이 오탐될 뻔한
  것을 300ms 대기로 정정해 재검증한 과정을 정직하게 보고.

**검수**:
- ✅ **마스터가 직접 재확인**: `git diff assets/css/style.css`로 실제 diff를
  읽고, 사용된 CSS 변수(`--color-accent-contrast`, `--space-2`, `--radius-md`,
  `--shadow-md`, `--font-size-sm`) 6개가 실제로 `:root`(라이트)와
  `@media (prefers-color-scheme: dark)`(다크) 양쪽에 정의돼 있음을 `grep`으로
  직접 확인 — 지어낸 변수 없음.
- ✅ `git diff --stat`으로 정확히 `assets/css/style.css` 1개 파일(+25줄)만
  변경됐음을 확인 — HTML은 건드리지 않았다는 보고와 일치.
- ✅ **마스터가 독립적으로 Playwright 재검증**(위 개발팀 검수와 별도로 CSS
  동작만 별도 측정): 4개 페이지에서 포커스 전 `.skip-link`의 `boundingBox().y`가
  `-100`, 포커스 후 `16`으로 정확히 이동함을 `getBoundingClientRect` 기반으로
  직접 측정해 확인. 콘솔 에러 0건.
- ✅ 기능(로직)을 건드리지 않았다는 원칙 준수 확인.
