  지역 허브 6개 그대로다.
- 지난 20여 일간 스킵 링크, WCAG 색상 대비, prefers-reduced-motion, schema.org
  JSON-LD, alt 텍스트, breadcrumb/footer-nav aria-current, focus-visible, 필터
  aria-live, `.post-intro` 스타일 등이 꾸준히 다뤄져 반복 감사 대상은 대부분 소진된
  상태였다. 코드를 직접 조사해 **아직 다뤄지지 않은 새 항목 3가지**를 찾아 지시했다.
  1. 지역 허브·발행 글 히어로 이미지(`post-hero-image`, 9곳) 전부에 `loading="lazy"`가
     붙어 있는데, 이 이미지는 페이지 최상단(above the fold)에 항상 보이는 요소라 지연
     로딩이 오히려 체감 속도를 늦추는 성능 버그임을 확인 → 개발팀에 지시.
  2. 사이트 전체 `<img>` 15곳 모두에 `width`/`height` 속성이 전혀 없어 브라우저가 CSS
     로드 전 원본 비율을 알 수 없음을 확인(`file` 명령으로 실제 픽셀 크기 확보) → 개발팀에
     같이 지시.
  3. 어제(09-26) 개발팀이 `about`/`contact`/`privacy` footer-nav에 추가한
     `aria-current="page"`가 스크린리더 전용이고 CSS 스타일이 전혀 없어, 화면으로 보는
     사용자는 현재 페이지를 구분할 수 없음을 grep으로 확인(breadcrumb는 이미 시각 스타일이
     있는 것과 비교) → 디자인팀에 지시.
  4. 지역 허브 필터(소지역/카테고리/음식종류)가 AND 조건 + 각 줄 단일선택으로 동작한다는
     점을 `assets/js/main.js`를 직접 읽어 확인했는데, "필터 결과가 하나도 안 나온다"는
     사용자 혼동에 대한 FAQ가 아직 없음을 확인 → CS팀에 지시.

## 5. 승인 필요 / 보류 항목

- **다음 콘텐츠(가나자와) 본문 작성** — 실제 스팟 리서치(WebSearch)가 필요한 기획팀

  `twitter:image`, JSON-LD/breadcrumb의 절대 URL화** — 실제 배포 도메인이 확정되어야
  활성화 가능. 기존부터 반복되는 보류 항목.
- **"예약 & 이동 정보"(제휴 링크) 미연동** — 실제 제휴 계약·외부 서비스 가입이 필요한
  사안이라 사용자 승인 없이는 진행할 수 없다. 오늘도 변경 없음.
- **실제 브랜드 파비콘 이미지** — 여러 세션에서 이미 "미확정으로 의도적 방치"로 결론난
  항목. 오늘도 새로 만들지 않았다(빈 `data:,` placeholder 유지).
- **다크모드 수동 전환 기능**, **실제 광고(AdSense) 게재 여부**, **협찬 표시 내부

  FAQ에서 이미 정직하게 "확정 계획 없음"으로 안내 중).
- **실제 배포(호스팅 연동) 여부**, **광고/제휴 실제 진행 여부·조건**, **실제 방문자
  문의 채널 확인** — 이번 세션 도구로는 확인할 수단이 없어 계속 보류.
- **오늘 신규 변경사항의 실제 브라우저 렌더링/LCP 측정** — 코드 레벨(diff 대조, 중괄호
  짝, grep 값 대조, 내부 링크 전수 검사, JS 문법 검사)로는 검증했으나, 실제 브라우저에서
  히어로 이미지 로딩 순서 개선 효과나 footer-nav 시각 스타일이 의도대로 보이는지는
  이번 세션에서 확인하지 못했다.
- 오늘 되돌리기 어려운 작업(강제 push, 파일/브랜치 삭제, 실제 메시지 발송, 외부 서비스
  가입/결제 등)은 전혀 수행하지 않았다.
